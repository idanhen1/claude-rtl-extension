# Privacy Policy

RTL Helper for Claude does not collect, store, sell, transmit, or share personal data.

The extension runs locally in the user's browser and only changes the visual text direction of Claude messages.

## Data collection

This extension does not collect user data.

## Permissions

The extension uses the storage permission only to save the user's enable/disable preference for the extension toggle.

The extension uses host access to https://claude.ai/ only to apply text direction improvements on Claude pages.

## Remote code

This extension does not use remote code.

All JavaScript and CSS are packaged inside the extension.

## Third parties

This extension does not send data to any third-party service.

## Affiliation

This is an independent helper extension and is not affiliated with Anthropic or Claude.
